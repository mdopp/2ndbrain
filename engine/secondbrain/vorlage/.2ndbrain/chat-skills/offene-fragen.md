Kein Modell: Fragen und Antworten verarbeitet der Code (`atlas_vorschlaege.py`, dieselben Fragen wie
`2ndbrain kanon-vorschlaege`). „ins Review" schreibt ins Review-Paket des Tages
(`reports/atlas-review-<datum>.md`), „übernehmen" trägt das Feld auf der System-Seite ein, getippter Text
wird als Einordnung gespeichert; ein Themenname der Landkarte (Bereich oder Unterbereich) wird bei Bereichs-Fragen
direkt zum Bereich.
